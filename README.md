# substrate-layer — P9 Substrate

README.md — repository purpose and layer contract for P9 Substrate.

Function:
    This repository implements primitive layer P9 of the Forge Stack:
    the semantic memory graph. It stores Entities, Subjects, Claims,
    and Evidence, and manages claim supersession. It consumes P1, P2,
    and P8 for its underlying primitives.

Layer:    P9 — Substrate
Depends:  P1 Envelope v2, P2 Sign, P8 Store
Consumed: P12 Rules, P13 DataCube, SC-OS
